  AI STAR CUBE · 精简快捷键（F1 开/关本页）
═══════════════════════════════════════════════════════════

【作用域】仅 WezTerm 窗口聚焦时生效（不是系统全局）

【核心 F 键 — 只记这些】
  F1   本速查（可能被系统帮助抢走；可再 F1 关）
  F2   （不绑）留给 AI Agent 自身
  F3   新建本地项目（严格4步：名 → 位置列表 → Agent/CLI → 确认）
  F4   关闭当前窗格（有确认）
  F5   重载 WezTerm 配置
  F6   三栏 AI 桌（先选 agent：已装 agent 平权列表，默认=任务路由排第一，↑↓+Enter / Esc 取消）
  F7   左侧 Explorer（先点 AI 对话窗格再 F7，同 DESK）

【不用快捷键的入口】
  标签栏「+」 / 冷启动   → Init 静态面板（wz> 输任务号+Enter → agent> 输模型号/Enter=默认/q 取消；熟手秒杀：两位数<任务><agent>一次直启，如 13=任务1+第3个agent，n13=强制新会话；c=新建向导；屏幕只在状态变化时重绘；启动成功后 Init 页签自动关闭，取消/失败不关闭）
  鼠标点页签             → 切换项目
  Ctrl+Shift+C / V       → 终端复制/粘贴文字
  AI 对话里 Ctrl+V      → 可粘贴图片（壳不拦截 Ctrl+V）

【新建项目 F3 · 四次输入】
  1 项目名
  2 位置列表 1-8（最优路径已算好）；0=只输入父目录
  3 Agent/CLI 单一选择（开放扫描包元数据/manifest/本地注册；同时写入 desk-roots 第三列）
  4 确认 Y → 建目录+绑定+启动

【多 Agent · D-016 开放探测】
  本机全部自描述 Agent 常驻 Init 的 2 AGENT 区；冷启动自动重扫，r 可原地重扫；无产品白名单
  静默单文件 CLI 可填 workbench/agent-registry.local.tsv，格式：id<TAB>label<TAB>命令或绝对路径（可用 | 分隔别名）
  两步同屏：wz> 输任务号，再 agent> 输 Agent 号（默认=该会话/任务路由）
  COMMAND 三列固定对齐，仅 a/r/q 二级操作；无产品专属 Dashboard
  文件/会话读取的猫猫进度与统一真实计数同步；未知时长的 Agent 启动只显示循环等待动画

【刻意不做】
  Leader 组合键、F8 续聊键、F9 选项目键
  续已有对话 → 点「+」进 Init → wz> 输任务号 → agent> 直接回车（默认=该会话的 agent，即续）
